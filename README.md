# Ecosistema Longitudinal de Aprendizaje en Tecnología e Informática

Framework curricular portable, modular y progresivo para los grados 6° a 11°, alineado con las Orientaciones Curriculares del Ministerio de Educación Nacional de Colombia.

## Propósito

Construir un currículo de Tecnología e Informática basado en competencias acumulativas, proyectos integradores y documentación longitudinal, con una arquitectura de conocimiento computable.

## Estructura del repositorio

- `00_framework_pedagogico/` – visión, macrocompetencias, metodología, progresión, ecosistema tecnológico, portafolio.
- `01_curriculo_base_men/` – competencias y evidencias oficiales del MEN.
- `02_mapping/` – conexión entre proyectos y evidencias MEN.
- `taxonomy/` – vocabulario controlado (modalidades, niveles, tipos de producto, etc.).
- `schemas/` – esquemas JSON para validación estructural.

## Uso

Este repositorio es la fuente de verdad para implementaciones curriculares, planeaciones automáticas y generación de reportes.
